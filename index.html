BẮT ĐẦU HÀNH TRÌNH FRONTEND

Học cách xây dựng một trang web linh hoạt.

Từ HTML cơ bản đến CSS Flexbox, mỗi bài thực hành giúp bạn hiểu cách tổ chức nội dung và tạo giao diện phù hợp với nhiều thiết bị.

Bài viết nổi bật

01 · HTML

Xây dựng cấu trúc

Chia trang thành Header, Navigation, Main Content, Sidebar và Footer.

02 · FLEXBOX

Sắp xếp linh hoạt

Dùng flex-direction, flex-grow và flex-wrap để kiểm soát bố cục.

03 · RESPONSIVE

Thích ứng màn hình

Dùng Media Query để đưa sidebar xuống dưới nội dung trên điện thoại.

Lộ trình thực hành

  1. Viết cấu trúc HTML có ý nghĩa.
  2. Thiết lập bố cục desktop bằng Flexbox.
  3. Điều chỉnh bố cục cho mobile.
  4. Kiểm tra và chia sẻ mã nguồn lên GitHub.

BẢNG TIN

Tin học tập

  • Thực hành bố cục Flexbox hai cột.
  • Kiểm tra hiển thị trên điện thoại.
  • Hoàn thiện bài tập và lưu mã nguồn.

Mẹo Flexbox

Đặt min-width: 0 cho Flex Item để nội dung có thể co lại trong cột.
